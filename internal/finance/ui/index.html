        A RECOVERY PLAN
        Encrypted backups, with your own passphrase
        First open your budget → Settings → Export data. Choose that native ZIP below. Finance encrypts it before download or a copy to My Drive. Manual export passphrases are not saved.
        Server snapshots
        Save the last synced version of every budget without unlocking end-to-end encrypted budgets. Provider credentials and login sessions are excluded. Use a separate backup recovery passphrase.
        Daily snapshots and retention
        While enabled and this server is running, snapshots run daily and recover missed runs after startup. To run without your browser, Windows stores this backup recovery passphrase under your Windows account protection. Your budget encryption passphrase is not needed.
        Restore a server snapshot (.mfs)
        Server recovery restores to a stopped, empty Finance server and preserves the old installation. Existing budgets are never overwritten. Use the recovery steps in the Windows guide; for an individual budget, use the .mfb restore below.
        Server snapshot recovery guide ↗
        Individual budget export (.mfb)
        Verify or restore an encrypted backup
        Choose your .mfb file and enter its recovery passphrase. After verification, download the original budget ZIP and use Actual's Import budget to restore to a new budget. This does not overwrite an existing budget.
        Provider private keys and the server credential store are not included. Reconnect banks after recovery. Up to 64 MiB per budget export. Keep a verified backup and your passphrase separately. Daily snapshots are optional and disabled until you enable them.
        

        PRIVATE BY DESIGN
        Make sharing a deliberate choice
        Actual stores your ledger in your browser and syncs it to your Windows server. Enable budget end-to-end encryption in Actual's settings if you want it; remember its separate passphrase.
        Budget encryption does not encrypt native provider credentials. Those remain server-readable inside your protected Windows app folder. Use Windows disk encryption and a trusted household server account.
        Household members can work on budgets you explicitly share. Everyone with access sees the whole shared budget; keep private spending in a separate budget or instance. A read-only viewer role is not available.
        Money manager is optional. It sends a reviewed summary to your chosen OpenAI or DeepSeek account only when you ask. API keys are protected on the server and belong to your OneAccount. Raw transactions, payees and notes are excluded. The app cannot protect data from a compromised Windows account or server.
